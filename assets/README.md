# AUREL — Eternal Adolescence

RisuAI 캐릭터 봇 **오렐 발랑쉐(Aurel Valençay)** 소개 페이지.

## 배포 (GitHub Pages)
1. 이 폴더 내용을 새 저장소 루트에 업로드
2. Settings → Pages → Source: `Deploy from a branch`, Branch: `main` / `(root)` → Save
3. 몇 분 뒤 `https://<아이디>.github.io/<저장소명>/` 에서 확인

## 다운로드 버튼
`index.html`의 다운로드 버튼은 `Aurel.charx`를 가리킵니다.
- 저장소 루트에 `Aurel.charx`를 올리거나
- 외부 링크를 쓰려면 `href="Aurel.charx"` 두 곳을 원하는 URL로 교체
